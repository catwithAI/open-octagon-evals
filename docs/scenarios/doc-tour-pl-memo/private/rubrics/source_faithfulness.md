# source_faithfulness v1

## Question

备忘中的每一条事实陈述是否都能在参考工作簿中找到依据？

## Criteria

- 站点、国家、金额、税率、日期等事实是否与参考文件一致
- 是否出现参考文件中不存在的站点、费用项、人物或说明
- 推断性结论（如"表现优于预期"、"成本控制良好"）是否被标明为推断，而不是写成事实

## Anchors

| score | label | 可观察状态 |
|---|---|---|
| 0.0 | unsupported | 至少一条事实陈述在参考文件中找不到依据，或与参考文件矛盾 |
| 0.5 | partial | 所有事实陈述都能在参考文件中定位，但至少一处推断性结论没有标明为推断 |
| 1.0 | supported | 所有事实陈述都能在参考文件中直接定位；所有推断性结论都有"估计"、"推测"、"基于……判断"之类的标记 |

选择规则：先查有没有 unsupported 的事实，有任何一条即为 0.0，不再往下看。没有则查推断标记，任何一处未标即为 0.5。两者都没有才是 1.0。

## Evidence

允许依据：

- `rendered_artifact`：agent 产出的 `tour_pl_memo.md` 全文
- `private/reference/ref_workbook.md`：参考工作簿的确定性渲染文本

禁止依据：

- agent 的思考过程、说明、完成声明
- 任务 prompt 中的数字（税率等）。prompt 里的数字是任务要求，不是"参考文件中的事实"；备忘引用税率是否正确由 `revenue_facts` 维度核对，本维度只看它是否与参考文件冲突

输出要求：`evidence_refs` 中每一条给出备忘中的原句和参考文件中对应的行，或写明"参考文件中无对应"。

## Notes for reviewer

- 数值容差 1 USD。四舍五入导致的个位差异不算矛盾。
- 汇总数字（Total Net Revenue 等）由备忘自己的表格加总而来，不要求在参考文件中逐字出现；只要加总的各项在参考文件中有据即算有据。
- 城市名的常见别名（如 Munich / München）不算不一致。
- 参考文件中不存在的站点名，无论金额多少，直接判 unsupported。
- 备忘如果说"本报告数据来自参考工作簿"，这是元陈述，不算事实陈述，不影响评分。
- 推断性结论的判定标准：一句话里包含对未来、原因或好坏的判断，且参考文件中没有对应字段。纯粹复述数字的句子不是推断。
- 备忘为空或不存在时，本维度状态为 `unavailable`，不是 0.0；产物缺失由 `structure_completeness` 和 gate 处理。
